# Parametrik mil: DIN ölçü seçimi

GOKWORKS Qt arayüzünden alınan ekran görüntüleri, 26 Ekim 2026.

## Segman yuvası — DIN 471

Ø30 mm mil için yuva genişliği 1,6 mm, radyal derinlik 0,7 mm ve yuva çapı 28,6 mm.

![DIN 471 segman yuvası seçimi](gokworks-segman-din471.png)

## Kama kanalı — DIN 6885-1

Ø35 mm mil için 10×8 mm kama kesiti, 5 mm mil kanal derinliği ve 32 mm toplam kanal boyu. Boy önerileri kalan kademe boyuna göre filtrelenir.

![DIN 6885-1 kama kanalı seçimi](gokworks-kama-din6885.png)
