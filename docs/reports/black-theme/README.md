# Siyah koyu tema — 09.10.2026

Ana zemin siyah (`#000000`); yan menü/panel/girişler siyaha yakın nötr tonlardır. İkincil düğmeler/hover mavimsi griden nötr siyaha çevrildi. Yeşil butonlar ve açık tema korunur.

**8 mevcut GUI testi geçti; başarısız veya atlanan test yok.** Metin/buton kontrastı, sekmeler ve çözünürlük/ölçek matrisi, tema tercihinin yeniden açılışı, çalışan işlem sırasında tema geçişi, K/R ve ISO tercihleri, 14 GD&T kartının iki temada çizimi ve rehber sınandı. Hesaplama kodu değişmedi; önceki tam 270 testlik rapor kendi sürümünün kaydıdır.
